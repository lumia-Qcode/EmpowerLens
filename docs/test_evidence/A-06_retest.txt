How a 'link' is identified: the participant link is /participant?cohort=<cohort_id> (or /participant + the workshop picker).
The app never identifies people, so 'the same link' = the same workshop opened in the same browser. The participant token
issued at consent is stored in that browser's localStorage under 'empowerlens.participant.<cohort_id>'. On opening the link the
page calls GET /api/participant/status/<token>; a completed token (or a closed workshop) shows 'This exercise is closed'.
Limitation: a different browser/device or a private window is not recognised (no login, by design).
